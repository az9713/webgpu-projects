The activation zoo, all twenty of them

Twenty activation kernels, all fed the same sweep of 201 points from −5 to 5, plotted on one panel with their derivative below. The derivative is not a separate kernel — it is a central difference taken in JavaScript over the values the GPU already returned. Untick a curve in the legend to pull it out of the crowd. The science

An activation function is the one deliberately non-straight step in a neural network. Without it, stacking layers gains nothing, because a chain of linear maps collapses into a single linear map. All twenty functions here bend the line; they differ in where they bend, how sharply, and whether they let anything through on the negative side.

Three families are visible. The rectifier family is flat below zero and straight above it, differing only in what happens to negative inputs. The sigmoid family saturates at both ends, which is what caused vanishing gradients in deep networks and drove the shift to rectifiers. The smooth-gate family multiplies the input by a soft switch, giving a slight dip below zero.

Several values at the origin are exact, and they act as correctness checks. Softplus(0) is ln 2, and the card returns 0.6931472. Sigmoid and HardSigmoid return 0.5. The other seventeen return 0.

The slopes at the origin are measured by a central difference over a step of 0.05, so most land near theory: Sigmoid 0.24995 against 0.25, Tanh 0.99917 against 1, Erf 1.12744 against 2/√π = 1.12838. Softsign is the exception at 0.95238, and it is not an error. Its central difference equals 1/(1+h) exactly, which for h = 0.05 is 1/1.05. Expect that value, not 1.

The two cheap approximations to Gelu differ from it by 4.7e-4 for FastGelu and 0.0203 for QuickGelu, the latter diverging most near |x| = 2, where the curve bends hardest.

Every call here is a single unary kernel: an input tensor x in, an output tensor the same shape out, no chaining, so there is nothing to keep on the card and no { output: "gpu" } handoff — each result is read back the moment it exists. Nine of the twenty take an attribute (alpha, beta, gamma, bias, lambd or approximate); the page tries the call with no attribute first and falls back to the ONNX-spec default value if that fails. PRelu also needs a slope tensor, filled here at 0.25 and shaped exactly like x rather than a broadcast scalar, since some kernels refuse to broadcast at all. FastGelu's bias input is optional, so the page tries without it and only supplies a zero bias if that call fails. The page records which argument key actually worked for each kernel in window.__result.argsUsed, and any kernel it could not call at all in window.__result.failed. Two curves are expected to sit exactly on top of each other: Celu at its default α=1 is algebraically identical to Elu at α=1. And because the derivative is a finite difference on a 0.05-wide grid, it smears every kink over one sample and is exact only where the true derivative is locally flat: Relu's reads 0.5, not 0 or 1, at the single grid point x=0, and Softsign's reads 0.952 there against a true 1.
