The science

Uniform symmetric quantisation replaces each weight with the nearest point on an evenly spaced grid. One scale s covers the whole tensor: s = max|w| / qmax, the stored integer is q = round(w/s), and the recovered weight is ŷ = s · q. Rounding to a grid of spacing s can be wrong by at most half a spacing, so the error is bounded by

|w − ŷ| ≤ s/2 = max|w| / (2 qmax), with an RMS error of s/√12 for errors spread evenly across a step.

For b bits the grid has qmax = 2b−1 − 1, which is 127, 7 and 1 at 8, 4 and 2 bits. The bound therefore predicts the 4-bit error to be 127/7 = 18 times the 8-bit error. The page measures 0.035 and 0.63, a ratio of 18.0. That agreement is the whole argument: the error is set by the single worst weight in the tensor, divided by the number of grid points.

Which is also the problem. One outlier stretches s for every weight that shares the scale, and the majority of small weights are then rounded on a grid far coarser than they need. This is why production int8 pipelines quantise per row or per channel rather than per tensor: it gives each row its own max|w|, so a single large channel can no longer tax the rest. Switch the scale mode and watch the error image change character — the bright rows go quiet.

Pipeline per panel: QuantizeLinear to int8 with scale = max|w| / qmax, then DequantizeLinear, then Sub, Abs, ReduceMax and ReduceMean for the numbers. qmax is 127, 7 and 1, so the 4-bit and 2-bit panels are symmetric grids of 15 and 3 levels. The kernels only store int8, so the 4-bit and 2-bit sizes are arithmetic, not measured buffers. Value panels clip the colour range at three standard deviations, or the outliers would hide everything else.
