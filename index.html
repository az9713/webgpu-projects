WebGPU kernel projects

Eleven small web pages that run real GPU maths in a browser tab, plus the research that chose them. Each page is one self-contained HTML file that imports @huggingface/kernels from a CDN. No npm, no bundler, no build step.

You need a browser with WebGPU — Chrome or Edge 113 and later, or Safari 26 and later.

  • The eleven pages →

    Quantum tunnelling, a painting machine with untrained weights, live MNIST training, slime mould, and six more. Each one names the kernels it calls.

  • The research report →

    Thirteen sections on how the library works and what the API costs you. Section 10 is measured on one laptop, not researched.

  • The project catalogue →

    121 project ideas in 18 categories, each with its exact kernel names and an honest ceiling, scored on seven axes in a sortable table.

  • The benchmark harness →

    The single file behind section 10. It runs in about 20 seconds and leaves its numbers in window.__result.

Built on Hugging Face's WebGPU kernels and announced in this video. Source and full notes: github.com/az9713/webgpu-projects. Independent work, not affiliated with Hugging Face.
